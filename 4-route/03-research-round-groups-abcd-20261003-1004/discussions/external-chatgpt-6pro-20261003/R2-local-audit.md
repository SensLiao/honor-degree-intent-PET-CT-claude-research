## 2. 单步门槛 oracle：重算能说明什么

来源：scripts/S_oracle_threshold_per_state.py 和同名 JSON。

| 符号 | 状态 / 患者 | 原 0.5 | 每状态最佳阈值或不改 | 只跳过 0.5 下有害编辑 |
|---|---:|---:|---:|---:|
| ADD | 103 / 52 | +0.02575994 | +0.04691019 | +0.03186134 |
| REMOVE | 97 / 51 | -0.01748220 | +0.03245135 | +0.02483655 |

这三个数都是对既有状态作一次编辑的 ΔDice，不是五轮结果。标准答案参与选择，只是诊断 oracle。

可由 JSON 重算：
- REMOVE 可挑选提升：0.03245135 - (-0.01748220) = 0.04993355。
- 理想地只辨别 0.5 是否有害带来的提升：0.02483655 - (-0.01748220) = 0.04231875。
- 两者比值约 84.75%。含义：在这批被抽取的旧状态上，辨别坏编辑是很有价值的轻量起点。它不说明可兑现 84.75%，更不说明 TEST 能升 4.2 点。

脚本先在每位患者内平均所抽取的状态，再患者等权；没有按照 scan→style→patient 的完整轨迹层级平均。200 个状态按患者×轮段×符号挑选，不是全体事件的随机样本，不能把该均值直接当完整交互分布的期望。
Spearman 的平均并列秩实现已修正；其 ADD -0.0469、REMOVE +0.0220 只说明当前未校准分数的最佳门槛与 D0 没明显单调关系，不能否定校准后理论。
最佳阈值的收益并列时偏向离 0.5 最近，故“最佳阈值”相关性还依赖该并列规则。报告中保留这一说明。
原始 sweep.jsonl 未附，本轮不能重新生成该 JSON；不应运行脚本失败后声称复现成功。

## 3. 比数字错误更重要的口径错误

### 3.1 “最大错误”不能重新实现成最大三维体积

A-internal-evidence.md 的追加问题末明确记录：
- FP 和 FN 各在单个轴向切片内找面积最大的 8 邻接分量，再画笔。
- 两侧候选笔由 choose_correction 比较笔体素数决定方向；并列 ADD。
- T 是当前 signed error 在原生网格的 18 邻接分量中，被笔真正碰到的所有分量的并集。
- 笔碰多块时取并集；没碰错误时 T 为空，不就近吸附。

原始生产源码未附，本轮依据上述代码审计记录。因此实施时应直接调用冻结模拟器和角色构建器，并核其实际版本，不能据 PLAN 简写另写“最大三维错误”机器人。新增训练选笔方式与官方评估方式分别登记。

### 3.2 95%、72%、90.6% 的分母不同

- “95% 的最终 gap 在第二轮后已出现”是两条独立轨迹曲线的差值比例，不等于 95% 的错误由第二轮制造。
- “近笔漏修至少 72% 被 e 挡住”来自 101 清单、体积加权的集合界；397 状态同圈下界约 50%，患者加权又不同。不能当所有自身轨迹的因果归因。
- “90.6% 的 ADD 带出 FP”只表示至少产生一点新 FP 的事件比例；不表示每笔有 90.6% 体素错误。

### 3.3 多训、停止与指标

一次 +8k 的 D5 区间跨 0，能写“本次未测到可靠 D5 提升”，不能写“多训无效”或“训练步数不是杠杆”的普遍结论。
用户主目标 D5 与论文已登记 nAUC 可并行保留：快速筛选按 D5 为主，完整表同时报告 nAUC；不得把原主指标静默换掉。
快速 VAL 采用每扫描一种画法；三画法 VAL 为每扫描三种，父子比较必须使用相同 roster。不能将 0.7602 与 0.7524 相减解释为方法收益。

### 3.4 功能前后相同不等于训练后相同

零初始化新通道只能保证初始化时 parent-compatible，不能保证联合训练后 D1 不变，也不能保证所有 random stream / optimizer state / augmentation 恒等。
不通过把新配方藏到未哈希常数里绕过 checkpoint 身份检查。应保留父模型原始哈希、建立显式迁移记录、生成子模型新配方/代码哈希，严格加载未改权重、记录新增权重。因架构变化允许 warm start，不允许伪装成原配方。

PLAN 说 workers 8→6、关闭 NumPy 大页后约 1.25 秒/步，但所引 records/server_status/z390-loader-memory-fix-20261003.txt 不在附件。本轮不能验证该速度或“结果不变”。

## 4. 本轮确认的数学边界

原生真实 Dice 在正 GT 且执行确为单向增删时，可由体素计数精确推导：
B=|M|+|G|，D=2|M∩G|/B，候选体积 k。
ADD 里新增真实病灶 a 个：ΔD=(2a-Dk)/(B+k)。
REMOVE 里删除真实病灶 a 个：ΔD=(Dk-2a)/(B-k)。

若候选分成被指目标 c、别处同向错误 o、正确区域 h，k=c+o+h：
ADD 真实 ΔD=((2-D)(c+o)-Dh)/(B+k)。
REMOVE 真实 ΔD=(D(c+o)-(2-D)h)/(B-k)。

因此“只用全局 ΔDice 训练选择器”确实会奖励 o，不能同时宣称仅修 T。屏蔽 O 的训练梯度只是不奖 O，也不构成推理时的禁止。

本轮曾推导、但经第二轮审查已撤下主线的指代效用 U_T（显式任务价值约定、不是标准 Dice）：
ADD U_T=((2-D)c-D(o+h))/(B+k)；
REMOVE U_T=(Dc-(2-D)(o+h))/(B-k)；
即 U_T=真实 ΔD−2o/(B±k)。

其中 2 来自把未经授权的同向修复，从“正确编辑”改计为“错误编辑”的代数差。代数正确不等于适合作为训练目标：REMOVE分母变小时，该值不是有界Dice差。例如M含1000个FP、GT为不相交的1体素、T只含其中1个FP，删光M的真实ΔDice=0而U_T=−1998。它不能解释成真实Dice下降，更不应未经审查放进软损失。Dice(M_A,M⊕T)同样会改变错误价格，并可能出现空目标平台；两项均未采用。

当前A改为分别预测真实native ΔDice g及范围外量 b=(o+h)/|F_legal|；F_legal是同一状态所有候选共享的实际合法footprint。预测b不大于同checkpoint同状态原0.5候选的预测b时，再按预测g选优，no-op恒为(0,0)。这是相对预测限制，不保证真实b不升或T外零修改。B保留原T/O/P、绑定与保持监督，新增O不获奖励的软收益。真实ΔDice、o、h独立记录。
scripts/R2-derived-checks.json仅验证现有JSON的算术和上述代数恒等式，并非对U_T目标有效性的验证，也没有重跑原始轨迹或新实验。

特殊状态不能略过：
- |M∩G|=0 时，正确 REMOVE 的即时 Dice 收益为 0，即使这一步能为下一轮 ADD 腾出机会；“严格大于0才改”可能永久拒绝。
- GT 为空的状态遵循冻结评测中 Dice 的定义/排除方式，另保留 FP 体积与保持监督；不能人为补 1 或造一个 epsilon 分数。
- 如果扩展到两步或剩余步的价值，no-op 自身的后续收益通常不为0；只有以它作参照的 advantage 才可固定为0。不同候选不能混用不同 horizon。

## 5. 可执行性缺口清单

生产网络/训练/评估源码、权重、原始 replay 和服务器配置未在附件中。本轮不会把审计脚本当生产实现。后续实施应优先确认：

4. 训练与推理无 G/T 访问路径；按患者划分 selector 拟合、OOF 与缓存键；

7. 最终记录完整五轮 D5/nAUC、范围外修改、no-op 与重访，而非只报单步头部 MSE。
