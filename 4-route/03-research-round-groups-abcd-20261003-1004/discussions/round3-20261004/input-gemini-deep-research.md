为网络自适应学习的动作迟滞阈值。该差分特征在编码器高层通过交叉注意力机制对当前轮次的候选编辑幅度施加自适应阻尼抑制。当上一轮发生大面积非稳态大幅修改时，阻尼通道显著抬高当前轮次空间扩散的阻抗，从系统动力学层面截断多轮次间的发散脉冲。期望效用决策与反事实因果约束建模为攻克多轮删除笔触累计净损失以及模型"改多大、改不改"的核心决策矛盾，系统将执行机制划分为连续候选生成与期望效用决策两个解耦阶段，并构建完备的反事实成对因果损失体系。期望效用门控模型与局部性保持传统的逐体素阈值化假定分类概率相互独立，而整例分割评价指标（Dice）是一个高度非线性的全局空间统计量：$$\operatorname{Dice}(M, Y) = \frac{2 \vert{}M \cap Y\vert{}}{\vert{}M\vert{} + \vert{}Y\vert{}}$$设当前分割掩码为 $M_{t-1}$，标准真实标注为 $Y$。若对空间区域 $\delta M$ 进行翻转编辑，则编辑后掩码为 $M_t = M_{t-1} \oplus \delta M$。整例 Dice 的真实变化量定义为效用函数（Utility）：$$\Delta \mathcal{U}(\delta M) = \operatorname{Dice}(M_{t-1} \oplus \delta M, Y) - \operatorname{Dice}(M_{t-1}, Y)$$在实际推理过程中真实标签 $Y$ 不可知。执行端接入轻量级效用预测网络 $\Phi_\psi$，该网络以图像局部与全局嵌入、当前分割统计特征以及候选修改区域为输入，预测执行该编辑后的整例 Dice 变化期望值 $\Delta \widehat{\mathcal{U}}$。基于基础修改倾向图 $P_t$ 与连通指代流形 $\Omega_t$ 的哈达玛乘积 $P_t \odot \Omega_t$，构建单调嵌套的候选编辑区域集合：$$\mathcal{C}_t = \left\{ \delta M^{(k)} = \mathbb{I}\left( P_t \odot \Omega_t \ge \theta_k \right) \;\middle\vert{}\; \theta_k \in \Theta \right\} \cup \{ \emptyset \}$$其中 $\Theta$ 为沿倾向图概率分布自适应采样的分位数集合（共 19 档动态划分），$\emptyset$ 表示不进行任何改动的零行动（No-Op）候选。决策器在推理时依照预测效用进行全局选拔：$$k^* = \arg\max_{k} \Phi_\psi \left( X, M_{t-1}, \delta M^{(k)} \right)$$$$M_t = \begin{cases} M_{t-1} \oplus \delta M^{(k^*)}, & \text{若 } \Phi_\psi \left( \delta M^{(k^*)} \right) > 0 \\ M_{t-1}, & \text{若 } \forall k, \; \Phi_\psi \left( \delta M^{(k)} \right) \le 0 \text{ （触发零行动拒绝）} \end{cases}$$当效用网络评估所有候选区域都将因连带误伤导致全局 Dice 降低时，系统坚决拒绝翻转任何体素，从而在机制上杜绝了后四轮删除操作中累计发生的 $-0.0497$ 负向损耗。双重反事实成对不变性损失针对因果干预原理，训练框架构建严格控制变量的成对监督机制，迫使网络学习高阶语义与空间指代因果链：目标干预变异性约束（Target Intervention Equivariance）要求模型在相同病患与相同分割状态 $M_{t-1}$ 下，面对两个空间独立的误差块 $E_A$ 与 $E_B$，当交互笔触分别指向 $S_A \in E_A$ 与 $S_B \in E_B$ 时，模型输出的修改预测 $\widehat{\delta M}_A$ 与 $\widehat{\delta M}_B$ 必须在空间上严格解耦。数学约束形式定义为：$$\mathcal{L}_{\text{target-inv}} = \frac{\vert{}\widehat{\delta M}_A \cap E_B\vert{}}{\vert{}E_B\vert{} + \epsilon} + \frac{\vert{}\widehat{\delta M}_B \cap E_A\vert{}}{\vert{}E_A\vert{} + \epsilon} + \mathcal{L}_{\text{Dice}}(\widehat{\delta M}_A, E_A) + \mathcal{L}_{\text{Dice}}(\widehat{\delta M}_B, E_B)$$该损失强行切断笔触 $S_A$ 对非指代错误目标 $E_B$ 的任何非预期修改，保障交互动作的局部隔离性（Locality）。笔触形态不变性约束（Stroke Morphology Invariance）要求针对同一目标错误 $E_A$，无论用户采用中心点触（Click）、骨架涂鸦（Scribble）还是外缘擦除线（Margin Stroke）进行标注（分别记作 $S_A^{(1)}, S_A^{(2)}, S_A^{(3)}$），模型内部推导出的连通指代流形必须保持严格空间一致性：$$\mathcal{L}_{\text{stroke-inv}} = \sum_{m \neq n} \left( 1 - \operatorname{Dice}\left( \Omega_t(S_A^{(m)}), \Omega_t(S_A^{(n)}) \right) \right)$$局部性保持损失（Locality Preservation Loss）借鉴大模型知识编辑中的保留集概念，针对当前分割状态中本已预测正确的空间区域施加绝对扰动惩罚：$$\mathcal{L}_{\text{locality}} = \frac{\Vert{} \widehat{\delta M} \odot \mathbb{I}(Y == M_{t-1}) \Vert{}_1}{\Vert{} \mathbb{I}(Y == M_{t-1}) \Vert{}_1 + \epsilon}$$基于 GradNorm 的自适应多任务梯度平衡为彻底消除 v1 版本中成对监督损失梯度被逐体素主损失稀释至 1/800 的数值瘫痪问题，系统集成基于梯度范数的自适应平衡算法。训练目标总损失定义为：$$\mathcal{L}_{\text{total}} = \lambda_{\text{task}} \mathcal{L}_{\text{seg}} + \lambda_{\text{util}} \mathcal{L}_{\text{utility}} + \lambda_{\text{pair}} \left( \mathcal{L}_{\text{target-inv}} + \mathcal{L}_{\text{stroke-inv}} \right) + \lambda_{\text{loc}} \mathcal{L}_{\text{locality}}$$在共享特征提取骨干的最后一层权重张量 $W_{\text{shared}}$ 处，算法实时采集各分项损失的反向传播梯度二范数 $G_i(t) = \Vert{}\nabla_{W_{\text{shared}}} \lambda_i(t) \mathcal{L}_i(t)\Vert{}_2$。根据各项相对初始时刻的损失下降比率 $r_i(t) = \frac{\mathcal{L}_i(t) / \mathcal{L}_i(0)}{\sum_j \mathcal{L}_j(t) / \mathcal{L}_j(0)}$，自适应调节权重动态演进：$$\frac{\partial \lambda_i}{\partial t} = \gamma \left( G_i(t) - \bar{G}(t) \times [r_i(t)]^\alpha \right)$$式中 $\bar{G}(t)$ 为所有任务项梯度的均值，$\alpha$ 为平衡敏锐度系数。该机制强制确保反事实成对损失与局部性损失在训练过程中的有效梯度占比恒定维持在 20% 至 35% 区间，彻底激活潜空间中的因果表征塑形。冲击 0.80 Dice 的高阶强组合实施路线与工程调度为坚决贯彻"以最高效率达成指标突破，避免在未达标前进行无价值消融"的核心原则，研发管线划分为四大有机衔接的推进阶段。各阶段的技术模块组合、工程依赖、算力耗时及目标指标在下表中进行了全面对齐：实施阶段序号与名称核心技术模块强组合训练与模型状态变更预计工程耗时验证集阶段目标 (VAL Dice)晋级判据与流转准则阶段零：吞吐性能调优数据加载进程数调整至 4-6
