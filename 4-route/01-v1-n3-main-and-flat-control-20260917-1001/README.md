# 第 01 阶段：v1 的两个模型，主线 N3 和 flat 对照（09-17 到 10-01）

## 为什么做

09-17 起 PET/CT 只留 SIRB-Net 一条主线（vault 任务页 T071 计划切换），先做出第一版，量清楚它能改好多少、丢在哪。

## 做了什么

09-17 到 09-25 备代码、核服务器上的数据和环境、审管线、做过拟合测试、生成训练语料、跑原型（vault T072 到 T077）。09-25 定下冻结前只比两个 state loss 版本，然后连训两个正式模型（`D-2026-09-25-01`）：

- 主线 N3：输出头拆成“有没有错”和“是哪块错”两步相乘。
- flat 对照：输出头对每个体素直接给 T、O、P 三类概率。

两个模型都从零训满 40,000 步，单种子 3407。09-28 导演授权两个模型各一次锁定测试（`D-2026-09-28-05`）；09-30 跑了锁定 TEST 和三种画法都跑的完整 VAL（`D-2026-09-30-02`、`D-2026-09-30-04`）。

## 结果

| 模型 | 三画法 VAL 第五轮 Dice（验证集） | TEST 第五轮 Dice（测试集，已登记） |
|---|---|---|
| 主线 N3 | 0.7366 | 0.7619 |
| flat 对照 | 0.7524 | 0.7694 |

起点是分割基座 0.6095（VAL）、0.6387（TEST）。用标准答案每轮把所指的错修好的理想参照，在 VAL 上是 0.9172，只当上限看。

## 发现

flat 对照比主线 N3 好；主线能改善原分割，但没超过同配方的 flat。v1 丢分在哪里的精确记账是 10-04 做的，放在第 03 阶段。

## 当时的决定

10-01 起进入第二版（`D-2026-10-01-02`、`D-2026-10-01-03`），目标改成最终 TEST 超过全部基线。

## 留下了什么

flat 成了后面所有组合的底子；N3 线 10-04 结束（`D-2026-10-03-03`）。v1 flat 40k 在快速 VAL 上是 0.7562，是 K 系列同口径的参照。
