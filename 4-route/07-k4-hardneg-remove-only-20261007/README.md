# 第 07 阶段：K4，只改难负样本（10-07 起，进行中）

## 为什么做

第 06 阶段的归因指向 B1 难负样本：它帮了删笔，拖了加笔。按 Dice 的账，加笔加进去的体素只要有三成多是真病灶就划算，删笔要删对七成以上才划算，所以只罚“删笔删掉真病灶”这一种。

## 做了什么
